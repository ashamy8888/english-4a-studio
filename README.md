# 沪教四上英语成长屋 · Shanghai 4A English Studio

基于**《义务教育教科书（五·四学制）英语 四年级 上册》（上海教育出版社 · 2024 审定，主编：束定芳）**打造的全册 10 单元互动学习网页。

## 核心功能
- **🗺️ 全册 10 单元成长地图**：100% 同步 Unit 1–10 原版课程内容（共 112 个原版词条、60 道语法互动题、30 轮课本情景口语对话、10 套原版 Project 写作支架）。
- **🔤 记单词**：彩色音节拆解 + 0.75x 慢速/常速朗读 + 拼图补全 + 模拟学校真听写（错词自动进「错词小怪兽」，连对 2 次移出）。
- **🧩 学语法**：同步每单元 `Find the rule` 口诀 + 句子积木工坊 + 语法小医生找茬改错。
- **🎤 开口说**：还原课本 `Talking time` 角色对话，提供 Lv.1 跟读逐词高亮 / Lv.2 关键词提示 / Lv.3 情景应答三档扶手。
- **✍️ 练写作**：三色拆解课本范文 + 分步引导写句 + 写作小侦探实时体检 + 一键导出高清 PNG 手账卡。
- **📊 错题消灭站 / 我的作品墙 / 家长小报告**：进度本地持久化保存，支持 JSON 备份导出与导入。

## 在线访问
开启 GitHub Pages 后即可访问：
`https://ashamy8888.github.io/english-4a-studio/`

## 本地运行
直接双击 `index.html` 在浏览器打开，或运行：
```bash
node server.js
```
然后访问 `http://127.0.0.1:8088`（推荐使用 Chrome / Edge 浏览器以获得最佳语音识别体验）。
